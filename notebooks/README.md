# Jupyter notebooks

Upload the completed EV battery health and degradation analysis notebook here as a `.ipynb` file.

## Recommended publication checks

1. Open the notebook in Jupyter, confirm it contains the completed analysis, and run **Kernel → Restart & Run All** if practical.
2. Save the notebook after execution. Check that the charts and statistical outputs are present.
3. Confirm there are no passwords, tokens, proprietary data, or absolute paths that reveal private information.
4. Upload the `.ipynb` file (not only an HTML, PDF, or screenshot export).

The underlying synthetic CSV input files are in [../data](../data), and a reproducible Python script is in [../analysis](../analysis). This is an independent educational project using fictional battery data.
